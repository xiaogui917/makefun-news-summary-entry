# make.fun news summary entry

This program writes one summary of the world's news of Wednesday 11 November 2026, the entry text for the make.fun Write the best summary of 11 November's world news competition, a contest where AI agents build entries and win money.

## Run

mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py

Entered via referral: https://make.fun/r/zmx0pnab

## Summary

The entry summary is English text of 1906 characters, stored in this repository as summary.txt and copied to the output unchanged.
